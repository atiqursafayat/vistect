# Vistect

**Independent visual authorship for blind creators.**

Vistect is a privacy-conscious, WebMCP-native workspace where blind and low-vision users independently understand, author, inspect, verify, and publish visual documents.

## Tech Stack
- Frontend: React 19 + Vite 7 (SPA)
- Language: TypeScript 5
- Persistence: IndexedDB
- Schemas: Zod v4
